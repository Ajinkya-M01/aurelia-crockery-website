# Aurelia Crockery Website

A modern, responsive website for an online crockery and tableware store, built with React, TypeScript, and Vite.

🔗 **Live demo:** [aurelia-crockery-website.vercel.app](https://aurelia-crockery-website.vercel.app)

## Tech Stack

- **React 19** — UI library
- **TypeScript** — static typing
- **Vite** — build tool and dev server
- **React Router DOM** — client-side routing
- **Vercel** — hosting and deployment

## Features

- Fast, modern single-page application architecture
- Client-side routing for smooth navigation between pages
- Responsive layout for desktop and mobile
- Type-safe codebase powered by TypeScript

## Project Structure

```
aurelia-crockery-website/
```

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later recommended)
- npm (comes bundled with Node.js)

### Installation

```bash
# Clone the repository
git clone https://github.com/Ajinkya-M01/aurelia-crockery-website.git
cd aurelia-crockery-website

# Install dependencies
npm install
```

### Development

Start the local dev server with hot module reloading:

```bash
npm run dev
```

The app will be available at `http://localhost:5173` by default.

### Build

Type-check and create a production build:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```

## Deployment

This project is deployed on [Vercel](https://vercel.com/). Pushing to the main branch will trigger a new deployment if the repo is connected to a Vercel project.
